Classic-X Menu for Trinity Desktop (TDE)

Classic-X is an ultra-fast, lightweight, and modern Start Menu replacement applet for the Trinity Desktop Environment (TDE / Q4OS).

Key Features:

  • Instant Type-to-Search: Start typing anywhere to search apps instantly without clicking the search bar.
  • Typo-Tolerant Fuzzy Engine: Intelligent suggestions with multilingual accent normalization (e.g. é, è, ê → e).
  • 20 Built-in Preset Profiles: Retro, Classic, Windows, Amiga, Atari, Mac, Dark, Minimal, and Q4OS native themes.
  • Interactive Quick Sidebar: Direct one-click access to Documents, Pictures, Terminal, Settings, and Power Management.
  • Extensive Visual Theming: Custom top headers, sidebar textures, fonts, RGBA transparency, and dynamic banner overlays.
  • Zero Memory Overhead: Highly optimized C++ / TQt3 architecture with zero background daemon overhead.
